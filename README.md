# Node.js + TypeScript + Fastify + Prisma API Starter Kit

Template profissional para APIs RESTful de alta performance construídas com **Node.js**, **TypeScript**, **Fastify**, **Prisma ORM**, **Zod** e **Swagger/Scalar**.

## 🚀 Tecnologias

- **Node.js** & **TypeScript**
- **Fastify** (Web Framework de alta performance)
- **fastify-type-provider-zod** (Validação e tipagem estrita de rotas)
- **Prisma ORM** (Modelagem e manipulação PostgreSQL)
- **Zod** (Validação de schemas)
- **JWT & Bcrypt** (Autenticação e hashing de senhas)
- **Swagger UI & Scalar** (Documentação OpenAPI automática)
- **Pino** (Logger estruturado)
- **Docker & Docker Compose** (Ambiente local de banco de dados)
